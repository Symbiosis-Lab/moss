# Contributing

## How to participate

- **Questions / patches**: open an [Issue](../../issues). Attach code as a fenced block, gist link, or `.patch` file.
- **Bug reports**: open an [Issue](../../issues) (use the bug report template).
- **Pull requests**: open one against `main` in this repo.
- **Security**: see [SECURITY.md](SECURITY.md). Do not file public issues for vulnerabilities.
