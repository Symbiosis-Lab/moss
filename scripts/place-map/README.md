# Place-map source boundary

`generate.py` is the offline source boundary. It verifies the exact source manifest, archive bytes, required shapefile sidecars, and GMT server manifest. `generate.mjs` is the only pack producer: it consumes that verified cache, decodes the pinned shapefiles and GMT NetCDF-4 relief grid, simplifies and quantises the geometry, and writes the checked-in binary pack.

Put the pinned source objects and `earth_relief_server.txt` in a separate cache, then run `MOSS_PLACE_MAP_SOURCE_DIR=/path/to/cache python3 generate.py --check` followed by `MOSS_PLACE_MAP_SOURCE_DIR=/path/to/cache pnpm generate`. The cache is intentionally outside the repository; a missing object or hash mismatch is an error and never triggers a network fallback. The generator writes `crates/moss-build/data/place-map/place-map-v1.bin` and its machine-readable size report. The checked-in pack is capped at 2.75 MiB.

The pack is `MOSSPLM1`, schema 1. Its fixed header contains the quantisation factor, WGS84 extent, tier/layer counts, 10-degree tile size, the SHA-256 of this source manifest, and ten stable layer-to-source-member bit masks. Each tier then contains length-delimited layer records; each feature carries an integer bounding box, a signed band threshold, and delta/zig-zag varints for its parts. The final record is a global 10-degree tile index into the fine-tier feature sequence. Tier 0 is the world inset and tier 1 is the locator geometry. Layer IDs are stable: coast 1, land 2, lakes 3, rivers 4, ice 5, reefs 6, salt flats 7, built-up 8, relief 9, sea floor 10. Relief and sea-floor thresholds come from pinned `d3-contour` isobands over the 0.5-degree sample of the GMT grid; the deepest Natural Earth bathymetry band is retained as a coastline-safe floor. Unknown schemas and layer IDs are rejected by the Rust decoder.

The source manifest records the Natural Earth layer release metadata, exact ZIP members, SHA-256 values, and public-domain notice. The GMT server manifest is pinned by date and SHA-256; because that upstream manifest does not publish a separate licence statement, `NOTICE` preserves that limitation instead of asserting one.
