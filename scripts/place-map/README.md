# Place-map source boundary

`generate.py` is the offline source boundary. It verifies the exact source manifest, archive bytes, required shapefile sidecars, and GMT server manifest. `generate.mjs` is the only pack producer: it consumes that verified cache, decodes the pinned shapefiles and the two GMT relief grids, simplifies and quantises the geometry, and writes the checked-in binary pack. Decoding the locator-tier relief grid shells out to the `opj_decompress` CLI from the openjpeg project (for example `brew install openjpeg` or `apt install openjpeg-tools`), the same way the source verifier already requires `python3`.

Put the pinned source objects and `earth_relief_server.txt` in a separate cache, then run `MOSS_PLACE_MAP_SOURCE_DIR=/path/to/cache python3 generate.py --check` followed by `MOSS_PLACE_MAP_SOURCE_DIR=/path/to/cache pnpm generate`. The cache is intentionally outside the repository; a missing object or hash mismatch is an error and never triggers a network fallback. The generator writes `crates/moss-build/data/place-map/place-map-v1.bin.br` and its machine-readable size report. That file is the pack brotli-compressed at quality 11, not the raw `MOSSPLM1` bytes: it is what `place_map::embedded()` embeds verbatim via `include_bytes!` and decompresses once at runtime, so it is also what the budget below measures. The checked-in pack is capped at about 3.4 MiB (3,565,158 bytes) of brotli-compressed bytes in that `.br` file, with a 5% margin enforced by the generator and by `scripts/place-map/test_generate.mjs`. The generator checks the budget before writing, so a run over it fails without replacing the checked-in pack or its report; `place-map-size.json`'s `raw_bytes` is the pre-compression size, kept for per-layer diagnostics only, and `brotli_bytes` is the gated figure. The budget only ever moves down from here. It sits above the approved-resolution pack's own measured size (about 3.26 MB, including the shelf-sea bands) rather than at it, because the biggest lever still on the table — storing each relief and sea-floor band's shared boundary once instead of once per band — is estimated to save roughly another 0.4 MB and hasn't been built yet.

The pack is `MOSSPLM1`, schema 2. Its fixed header contains the quantisation factor, WGS84 extent, tier/layer counts, 10-degree tile size, the SHA-256 of this source manifest, and ten stable layer-to-source bit masks (opaque to the decoder; a mask names which logical source datasets feed a layer, not a literal per-file index). Each tier then contains length-delimited layer records; each feature carries an integer bounding box, a signed 16-bit band, and delta/zig-zag varints for its parts. The band is a relief or sea-floor feature's threshold, and a river's Natural Earth `scalerank` (0 for the largest rivers), which the renderer uses to taper river strokes; every other layer stores 0. The final record is a global 10-degree tile index into the fine-tier feature sequence. Tier 0 is the world inset and tier 1 is the locator geometry. Layer IDs are stable: coast 1, land 2, lakes 3, rivers 4, ice 5, reefs 6, salt flats 7, built-up 8, relief 9, sea floor 10 — but schema 2 never stores a coast record: Natural Earth's coastline and land datasets trace the same digitized shoreline, so the renderer draws every coast from land's own rings instead of storing both independently: a map's coast is a soft halo of its land paths, and the globe inset's coast lines come from a layer the decoder derives from world-tier land (`place_map.rs`'s `synthesize_world_coast`). Relief thresholds are `100, 200, 400, 700, 1000, 1500, 2000, 2500, 3000, 4000, 5000, 6000`. Sea-floor thresholds are `-6000, -5000, -4000, -3000, -2000, -1000, -200, -100, -50, -30, -20, -10`, including three shallow shelf-sea steps so shelf seas render distinctly instead of flattening to one deep-water tone. A relief band is the ground at or above its threshold; a sea-floor band is the water at or below its threshold, that is at least that deep, traced from the negated grid. Both ladders therefore nest and shrink away from sea level, which is the order the renderer paints them in. Both ladders are data carried in feature bands; the decoder does not prescribe their count or values. The thresholds come from pinned `d3-contour` isobands: the world tier still traces a 0.5-degree sample of the 6-arcminute GMT grid, but the locator tier traces the 3-arcminute GMT grid at its native resolution (no stride) so relief and sea-floor bands hold their shape down at locator scale. The deepest Natural Earth bathymetry band is retained as a coastline-safe floor. Unknown schemas and layer IDs are rejected by the Rust decoder.

Locator-tier simplification also splits by role: land (the sole source of the coast stroke) is Douglas-Peucker simplified at 1 device pixel, every other layer (lakes, rivers, ice, reefs, salt flats, built-up, relief, and sea-floor bands) at 2 device pixels, both measured at the roughly 10-degree-wide, 720px-wide locator frame. Because coast is now always land's own ring boundary, the two can no longer disagree at render scale the way two independently-simplified datasets could.

Both ladders are in the grids' stored units, not metres. The GMT server stores `earth_relief` as 16-bit integers with a scale factor of 0.5 (the 6-arcminute grid's `z` variable carries `scale_factor = 0.5`, and the server manifest lists 0.5 for the 3-arcminute tiles), and the generator reads the stored integers without applying it. A stored unit is therefore half a metre: the `100` band traces ground about 50 m up and the `-6000` band traces water about 3,000 m deep. This is deliberate. The approved basemap design was drawn from the same unscaled values, so applying the scale without also halving both ladders would change its look; doing both is a design change, not a fix.

The source manifest records the Natural Earth layer release metadata, exact ZIP members, SHA-256 values, and public-domain notice. The GMT server manifest is pinned by date and SHA-256; because that upstream manifest does not publish a separate licence statement, `NOTICE` preserves that limitation instead of asserting one.
