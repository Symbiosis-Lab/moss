The moss window puts your files, the page you are writing, and the finished site beside one another. Changes appear in the preview as you write. Drag the divider when you want more room, or close either side and concentrate on one thing.

![Map of the moss editor: the file breadcrumb and writing surface sit beside the live preview; numbered details point to choose, edit, preview, and publish controls](../assets/guides/editor-map.svg)

*Editor and preview, assembled from captured interface views. 1. Choose a page from its breadcrumb. 2. Edit the page or type `/` for blocks. 3. Check the live preview and device view. 4. Review, then publish with the arrow.*

## Write in place

Select text to open the small formatting toolbar. It handles headings, emphasis, links, and other everyday formatting without asking you to remember Markdown.

On a new line, type `/` to open the insert menu. Use it for headings, lists, media, and moss layouts. If you already know Markdown, keep typing it: the source file remains an ordinary `.md` file that you can also open in Obsidian or any text editor.

## Keep the folder in view

The file tree is your site's structure. Create a file or folder there, rename it, or drag material in from Finder. Drop an image, video, audio file, PDF, notebook, or a whole folder into the tree to copy it into your site. Drop media into the page to insert it where you are writing.

When you rename a file or folder, moss updates links that point to it. Before deleting something other pages use, moss shows what would break.

## Work with the preview

Click a page in the preview to open its source. Click an image or other embedded file in the editor to find it in the preview. The preview uses the same theme and page structure as the published site, including light and dark mode.

For keyboard commands, see [Editor shortcuts](/docs/writing/editor/). To learn the source format, continue with [[Write with Markdown]].
