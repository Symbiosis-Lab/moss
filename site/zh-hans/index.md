# 随处写作，随处发布。一切由你掌控。

把文件夹打包成独立网站。右键，预览，发布。

:::grid 3
**本地写作**

Markdown 文件。使用内置编辑器、Obsidian、或者任意其他软件。
+++
**右键发布**

预览、确认、发布。同步到各平台。
+++
**独立网站**

选择托管服务。选择独立域名，或者使用默认域名。
:::

### 开放格式，本地优先

内容存于你的计算机中。用你的操作系统管理内容，用共享文件夹多人协作。网站从本地发布到服务器，迁移零成本。

### 通用方案，多种渠道

标准静态网页，部署在任何服务器。内容发表到独立网站与邮件列表，同步到各个平台，再同步回评论。

### 多种媒体，自动处理

视频、图片、HTML、Jupyter Notebook。放进文件夹，青苔处理其余一切。

### 无限扩展

通过 CSS 和 JavaScript 自定义设计，通过脚本插件自定义编译流程。尽情 vibe code，青苔让你的网站可读、可维护。

我们正在分批邀请写作者，一边打磨细节。你可以留下你的邮箱，等到你那一批，我们会发送一份构建版本，通常在报名后几周内。

只发一封邮件。只有当你的构建版本就绪，我们才会写信。
