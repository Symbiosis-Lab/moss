青苔是一个本地优先的网站建构与内容发布工具。**你的内容始终留在你自己的电脑上**，我们尽可能少地收集数据，**没有广告，也不追踪个人**。

这是一份早期的隐私说明。青苔仍在积极开发中，我们会随产品成长而不断完善这份文档。如有不清楚的地方，欢迎[联系我们](#联系我们)。

## 你的内容属于你

你的文件夹及其中的一切内容都保存在你自己的设备上，包括青苔建构的网站本身。当你选择发布时，数据才会离开你的电脑，此时青苔将网站与内容上传到你选择的服务器与平台。

你可以将青苔在本地建构的静态网站部署在任何地方。此时青苔服务器将不收集你的任何数据与信息（[崩溃报告](#崩溃报告)除外）。

## 你的账户

如果你发布到青苔的服务器，我们会使用你的电子邮箱和青苔为你自动生成的公钥（一个匿名加密标识）。我们将其保存在青苔的服务器上，以便识别哪些网站属于你。

## 支付

支付由位于美国的支付处理商 Stripe 处理。银行卡信息由 Stripe 保管，我们不接触你的卡号。我们仅保留你的 Stripe 客户 ID 和邮箱以管理订阅，收据由 Stripe 发送。

## 自定义域名

如果你通过青苔注册域名，域名注册商（位于加拿大的 OpenSRS / Tucows）需要 ICANN 联系信息，包括你的姓名、地址、电话和国家/地区；这是域名注册商的标准要求。我们会开启额外的 WHOIS 隐私保护，使这些信息不被公开，并且我们自己不存储它们，只保留域名和你的邮箱。如果你关联一个已经拥有的域名，则不会额外收集任何信息。

## 邮件订阅

如果你通过青苔支持邮件订阅，读者订阅时填写的邮箱地址会为你的网站保存在我们的服务器上，邮件通过 Resend（位于美国的邮件服务）发送。我们采用确认式订阅（double opt‑in），不存储读者的 IP 地址。作为站长，读者的数据由你负责；我们代你保管，方便你向他们发送邮件。

## 评论

如果你通过青苔开启评论，当有人在你发布的网站上评论时，其昵称（以及可选的邮箱和网址）、评论内容，以及基本的技术信息（IP 地址和浏览器）会保存在我们托管的评论系统中。这使得我们可以更好地识别恶意评论。如启用了回复通知，通知将通过 Resend 发送。

## 网站访问统计

对于已发布的网站（包括本站），我们保留基础的访问统计：被访问的页面、来源网站（只保留网站名称，不保留完整地址）、国家/地区、浏览器和操作系统类别、屏幕尺寸档位（手机、平板或桌面），链接中的活动标记（utm_source 与 utm_medium），以及网站标记为需要统计的按钮（如下载按钮）的点击次数。为了在不使用 Cookie 的情况下统计独立访客，我们的服务器会用一个每天更换、且从不保存的密钥，把访客的 IP 地址和浏览器信息转换成一个简短的代码。同一位访客在同一个网站、同一天内得到相同的代码；换一个网站或换一天，代码就完全不同且无法关联，因此没有人能跨网站或长期追踪读者。IP 地址本身从不存储。这些统计中不含 Cookie，也不做跨站追踪。我们在服务器上保留这些数据 400 天，之后删除。我们处理这些数据的依据是正当利益：让每个网站以尽可能少的数据了解自己的读者。

仅在本站（mosspub.com）上，我们还使用托管服务商 Cloudflare 提供的无 Cookie 统计工具 Cloudflare Web Analytics，用来与我们自己的统计相互对照。用青苔发布的网站不使用它。

如果你开启了数据面板，你的网站的数据会从青苔服务器同步到你的设备中，并在本地保存，你也可以在本地进行分析。

## 崩溃报告

如果青苔遇到错误，它可以向我们自己的服务器发送一份崩溃报告，帮助我们修复问题。这是青苔唯一自动上报的内容，不会追踪你如何使用应用。我们会剥离个人数据：不存储你的 IP（在到达我们的错误跟踪系统前已被屏蔽），文件路径也会被清理。你可以随时在**青苔 → 设置 → 崩溃报告**中关闭它。即使你没有关闭，崩溃报告会在 90 天后删除。

## 支持日志

如果你使用 **“发送日志”** 来反馈问题，青苔会在清理个人数据之后上传你最近的应用日志，并返回日志编号，方便你向我们报告错误，让我们能够尽快修复问题。这些日志会在 30 天后删除。

![[send logs.mp4|loop|100%|手动发送日志]]


## 数据在哪里处理

我们的服务器位于**美国**，我们依赖的部分服务（Stripe、Resend、Cloudflare）也在美国；我们的域名注册商（OpenSRS / Tucows）位于**加拿大**。如果你身处欧盟或英国，你的数据可能会在你所在国家/地区以外处理。

## 我们保留多久

崩溃报告：90 天。支持日志：30 天。你的账户、付款和订阅者记录会在你的账户或网站有效期间保留。你可以联系我们提前删除你的数据。

## 你的选择与权利

你可以要求我们查看、更正或删除你的数据，也可以随时通过应用内的开关拒绝崩溃报告。

## 联系我们

有疑问，或想删除你的数据？请发邮件至 **hi@symbiosis-lab.org**。
